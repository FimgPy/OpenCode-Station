Как запустить на компьютере друга (быстрый старт с нуля):

Шаг 1: Распаковать архив в любую удобную папку (например, D:\OpenCode-Station 
       или C:\OpenCode-Station).

Шаг 2: Запустить файл: windows\setup.bat
       - Скрипт автоматически проверит WSL. Если WSL еще нет на компьютере, 
         он сам установит Ubuntu из официального репозитория Microsoft.
       - Установит все компоненты OpenCode, ttyd, менеджер сред и утилиты.
       - Настроит профиль командной строки и рабочее окружение.

------------------------------------------------------------------------------
ВАРИАНТЫ ЗАПУСКА:
------------------------------------------------------------------------------

1. ПОЛНОЦЕННАЯ ГРАФИЧЕСКАЯ ПАНЕЛЬ (GUI):
   - Запустите: windows\start_gui.bat
   - Откроется панель управления на http://localhost:7682:
     * «Среды и Сессии»: управление анонимными изолированными средами,
       мгновенный переход в актуальную сессию OpenCode или запуск новой,
       сброс кэша и регенерация паспорта устройства (Machine ID) в 1 клик.
     * «Файловый проводник»: изолированная рабочая Ext4-папка Linux,
       множественный выбор файлов (чекбоксы), удобный экспорт выбранных файлов 
       на Windows (D:\OpenCode-Station_Package\workspace), скачивание ZIP-архивом,
       Drag & Drop файлов прямо из Windows Explorer в Linux.
     * «Терминал CMD»: веб-терминал с поддержкой Ctrl+V, кнопками быстрого
       запуска opencode, dir, cls, myip, export и чистым выходом без артефактов.
     * «Прокси и Сеть»: автономная настройка HTTP/SOCKS5 прокси ДЛЯ КАЖДОЙ СРЕДЫ,
       проверка внешнего IP, защита от ошибок 403 через NO_PROXY.

2. ЗАПУСК ВЕБ-ТЕРМИНАЛА В БРАУЗЕРЕ:
   - Запустите: windows\start_web.bat
   - Терминал откроется на http://localhost:7681 со всеми возможностями.

3. ЗАПУСК КЛАССИЧЕСКОЙ КОМАНДНОЙ СТРОКИ:
   - Запустите: windows\start.bat
   - Откроется консоль в стиле Windows CMD.

macOS: запустите macos/install.command, затем macos/start.command.
Linux: bash linux/install.sh, затем ./linux/start.sh.

------------------------------------------------------------------------------
ГЛАВНЫЕ КОМАНДЫ В ТЕРМИНАЛЕ:
------------------------------------------------------------------------------
- opencode                 -> Запуск консольного редактора OpenCode
- kill-opencode            -> Корректный выход из OpenCode и очистка терминала
- ai <запрос>              -> Быстрая кодогенерация
- dir                      -> Список файлов текущей папки
- open                     -> Открыть рабочую папку в Проводнике Windows
- envs                     -> Список всех анонимных сред
- env create [имя]         -> Создать новую анонимную среду
- switch <имя>             -> Переключиться в изолированную среду
- env clean [имя]          -> Сбросить кэш и сменить паспорт среды
- proxy set <url>          -> Подключить прокси (HTTP / SOCKS5)
- proxy on / proxy off     -> Включение / выключение прокси
- myip                     -> Проверить внешний IP-адрес и геолокацию
- export all / select      -> Экспорт файлов на диск Windows (D:\OpenCode-Station_Package\workspace)
- help                     -> Список всех доступных команд

Вставка текста из буфера обмена: по сочетанию Ctrl + V.
