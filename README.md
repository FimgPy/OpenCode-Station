## 🌟 Ключевые возможности

- 🔒 **100% Анонимные изолированные среды:**
  - Каждая среда обладает уникальным аппаратным отпечатком (`Machine ID`), индивидуальным именем хоста (`Hostname`), независимым домашним каталогом (`~/.config`, `~/.local`) и отдельной базой данных сессий.
  - Сессии, история чатов и кэш из одной среды **никогда не пересекаются** с другой средой.
  - Каждая среда автоматически привязана к отдельной папке на диске Windows (`D:\OpenCode-Station_Package\workspace\<имя_среды>`).

- 🚫 **Полное подавление блокировок и лимитов:**
  - Встроенный машинный патч ядра OpenCode полностью блокирует всплывающие модальные окна `go-upsell` (*«Free limit reached»*).
  - Автоматическая преднастройка быстрой бесплатной модели `DeepSeek V4.1 Flash Free` (с контекстом до 1 000 000 токенов) для всех сред при создании.

- 🌐 **Индивидуальная маршрутизация и прокси:**
  - Поддержка протоколов **HTTP**, **HTTPS**, **SOCKS5** и **SOCKS5h**.
  - Встроенный локальный мост `opencode-proxy-bridge` для прозрачной маршрутизации трафика среды через SOCKS5.
  - Защита локальных loopback-адресов (`127.0.0.1`, `localhost`) для безотказной работы встроенного RPC.
  - Мгновенная проверка внешнего IP-адреса и локации среды через встроенную утилиту `myip` и веб-интерфейс.

- 💻 **Современный Web-интерфейс (GUI):**
  - Единый дашборд управления на `http://localhost:7682`:
    - **Среды и Сессии:** создание, переключение, очистка и удаление сред в один клик.
    - **Файловый проводник:** быстрый просмотр структуры проекта на диске Windows и в Linux с отображением размеров и типов файлов.
    - **Терминал CMD:** встроенный веб-терминал с поддержкой горячих клавиш (`Ctrl+C`, `Ctrl+V`), быстрых команд и смены сессий.
    - **Прокси и Сеть:** настройка прокси для каждой среды по отдельности со сводной таблицей статусов.

- 🚀 **Быстрый старт в Windows без сложной настройки:**
  - `setup.bat` — автоматическая установка и развертывание всех сервисов.
  - `start_gui.bat` — запуск всей станции и открытие веб-панели управления в браузере.
  - `start_web.bat` — запуск станции в режиме веб-терминала (`http://localhost:7681`).
  - `stop.bat` — корректная остановка всех фоновых процессов в один клик.

## 🛠️ Установка и первый запуск

### Системные требования:
- Windows 10 (версия 2004 и выше) или Windows 11.
- Включенный компонент WSL2 (скрипт `setup.bat` при необходимости установит Ubuntu автоматически).
- Не менее 2 ГБ свободного места на диске.

### Шаг 1. Клонирование репозитория

```powershell
git clone https://github.com/FimgPy/OpenCode-Station.git
cd OpenCode-Station
```

### Шаг 2. Развертывание станции

Запустите файл **`setup.bat`** (двойным кликом или из терминала):
- Скрипт проверит наличие WSL2 и Ubuntu.
- Настроит пользователя `dev`, выставит необходимые права и скопирует утилиты.
- При отсутствии ядра OpenCode автоматически загрузит актуальную версию с официального источника и применит патч снятия ограничений.
- Подготовит папку проектов на диске Windows (`D:\OpenCode-Station_Package\workspace` или `C:\OpenCode-Station_Package/workspace`).

### Шаг 3. Запуск

- **Для работы через Web GUI (рекомендуется):**  
  Запустите **`start_gui.bat`**. Откроется браузер по адресу `http://localhost:7682`.
- **Для работы в классическом терминале:**  
  Запустите **`start.bat`**.
- **Для остановки работы:**  
  Запустите **`stop.bat`**.

## 🕹️ Управление средами из консоли (CLI)

В любой момент внутри терминала доступна утилита `env`:

```bash
env                      # Показать список всех доступных сред и активную среду
env create <имя>         # Создать новую полностью изолированную среду
env switch <имя>         # Переключиться в указанную среду
env clean [имя]          # Очистить историю/кэш среды и перегенерировать Machine ID
env delete <имя> [-w]    # Удалить среду (-w: также удалить папку на диске Windows)
env myip                 # Проверить внешний IP-адрес и геолокацию среды
env proxy                # Управление настройками прокси
```
